
# Admin Dashboard for Capstone Project

## Overview
This is the `admin_dashboard` module for the Capstone Project, which provides a management interface for administrators. It allows administrators to manage bookings, customers, services or products, and feedback effectively.

## Features

## Customer Management: ( This feature will be completed for Sprint5)
- here we can we view,search,edit, delete and add customers.
- tables for each customer will be shown accordingly. This section has been fully worked on in sprint 5

## Offerings management
- here all available services will be seen by admins and can be deleted,added, edited accordingly.

## Booking/order Management
- Here the admin will the see the customers' orders or appointments and their status. Html and css code for this section has been worked so far(sprint5)


## Analytics
_ admin will look how business is going on in this section and make decsions accordingly

## Feedback
_ admin will see customers' feedback in here and take actions
